# خادم Call Free الوسيط

يربط المستخدمين خارج الشبكة المحلية عبر الإنترنت: يعرف من المتصل من جهات اتصالك، ويمرّر الرسائل والملفات (حتى 20MB) والمكالمات الصوتية.
لا يخزّن أي شيء على القرص — كل شيء في الذاكرة فقط.

## التشغيل المحلي
```
npm install
APP_TOKEN=مفتاح-سري PORT=8080 npm start
```

## النشر (اختر واحداً)
**Render.com (مجاني، يدعم WebSocket):** New → Web Service → ارفع هذا المجلد على GitHub واربطه.
Build: `npm install` — Start: `npm start` — أضف متغير البيئة `APP_TOKEN`.
العنوان يكون `wss://اسم-خدمتك.onrender.com`. (الخطة المجانية تنام بعد خمول فيتأخر أول اتصال ~30 ثانية.)

**Railway / Fly.io / أي VPS:** استخدم `Dockerfile` المرفق: `docker build -t callfree-relay . && docker run -p 8080:8080 -e APP_TOKEN=... callfree-relay`
ضع خلفه Nginx/Caddy لتفعيل HTTPS ليصبح العنوان `wss://`.

## الربط بالتطبيق
في التطبيق: ⓘ حول التطبيق ← «الاتصال عبر الإنترنت» ← أدخل عنوان الخادم (`wss://...`) والمفتاح نفسه `APP_TOKEN` ← حفظ.
يمكنك تثبيتهما كإعداد افتراضي في `AppInfo.kt` (`DEFAULT_RELAY_URL` و`DEFAULT_RELAY_TOKEN`).

## ملاحظات أمان
- استخدم `wss://` دائماً (وليس `ws://`) وإلا فالصوت والرسائل غير مشفّرة في الطريق.
- الخادم يرى المحتوى المار عبره (لا يوجد تشفير من طرف إلى طرف).
- `APP_TOKEN` يمنع غير مستخدمي تطبيقك من استعمال خادمك.
